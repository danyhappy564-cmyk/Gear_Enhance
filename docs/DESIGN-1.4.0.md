## 14. 파괴 방지권 (★★·★★★ 진화, 2026-10-25 사용자)

★★·★★★ 진화는 실패하면 장비가 파괴되고 기존 보호(파괴 방지)를 쓸 수 없습니다. 그래서 진화 전용 **파괴 방지권**을 둡니다.

| | ★★ 진화용 | ★★★ 진화용 |
|---|---|---|
| 장비 하나당 살 수 있는 수 | **최대 3장** | **최대 2장** |
| 1장 가격 (2026-10-25 사용자: 처음 300만·800만의 1/3) | **1,000,000 ₽** | **2,700,000 ₽** |

- **한도는 "평생" 기준**: 그 장비에서 산 장수를 세고, 한도까지 사면 다 써도 **더 살 수 없음**(`구매 3 / 3 (더 못 삼)`). 다른 장비는 따로 셈.
- 사는 곳: ★★성·★★★성 탭의 방지권 줄 `1장 구매 · 1,000,000 ₽`. 체크 `방지권 사용 (실패해도 장비 유지)`.
- 쓰는 법 (2026-10-25 사용자 변경): 체크하고 진화 시도 → **성공·실패와 관계없이 시도할 때마다 1장 소모**. 실패하면 장비·단계 그대로(결과 창 `진화 실패 · 파괴 방지권 사용 · 남은 N장`), 성공 결과 창에도 `파괴 방지권 1장 사용 · 남은 N장`.
- **★★용과 ★★★용은 따로**: ★★용 3장 한도는 ★★ 진화에서 끝. ★★ 진화에 성공하면 남은 ★★용은 ★★★로 옮겨지지 않고 **사라짐**(결과 창에 안내, 루블 환불 없음 — 2026-10-25 사용자 확정). ★★★용 2장은 0부터 따로 삼. ★★★ 탭에 `★★용은 못 씀` 표시.
- 방지권을 쓰는 시도는 파괴될 일이 없으므로 12.1의 파괴 확인 창을 띄우지 않음.
- 방지권은 장비에 붙어 있음(장비 ID 기준). 강화 보험 반환·플리마켓·사격장 복사본에서 장비 기록과 함께 따라감. 장비가 다른 이유로 파괴되면(??? 실패 등) 같이 사라짐. 팔거나 다른 장비로 옮길 수 없음.
- 가격: 처음엔 ★★ 진화 비용(최소 200만)의 1.5배·★★★(400만)의 2배(300만·800만)로 정했으나 사용자가 1/3로 내림(100만·270만, 장수 한도는 그대로). 시도마다 1장이므로 ★★은 "안전한 3번"에 300만, ★★★은 "안전한 2번"에 540만이 추가로 듦. F12 옛 기본값(300만·800만)을 그대로 둔 사람만 `밸런스 설정 버전` 4에서 옮김. 재료로 성공률을 올리면 그 3번(2번) 안에 성공할 확률이 오름(★★ 재료 최대 60% → 3번 안 성공 약 94%, ★★★ 재료 최대 40% → 2번 안 약 64%).

## 17. 강화 기록 위조 방지 (2026-10-25 사용자)

- 문제: 프로필 파일(`user/profiles/<id>.json`)의 `rfGearEnhance`를 메모장으로 고치면 강화 단계·별·방지권을 마음대로 바꿀 수 있었음.
- 대책: 서버가 저장할 때마다 기록에 **봉인(`Seal`, HMAC-SHA256)**과 **압축 사본(`Vault`, 사본 자체에도 봉인)**을 붙임. 저장은 서비스 잠금 안에서 해서 바뀌는 도중을 저장하지 않음.
- 서버 시작 때 봉인이 안 맞으면(손으로 고침) → 사본으로 되돌림. 사본도 망가졌으면 → 모드 폴더 `data/seals/<id>.vault`(마지막으로 정상 확인된 사본) → 그것도 없으면 강화 기록을 비움. 되돌리면 서버 로그 경고 + 게임 알림 1번.
- 봉인과 사본을 둘 다 지워 옛(1.3.0) 파일처럼 보이게 해도, 그 프로필이 모드 폴더에 사본이 남아 있으면 사본으로 되돌림.
- 순서·숫자 표기(5와 5.0)·키 순서가 달라져도 같은 값이면 봉인이 맞음(다른 도구가 파일을 다시 써도 안전).
- 한계: 열쇠가 DLL 안에 있으므로 모드를 뜯어 다시 만드는 사람은 막지 못함(개발자 비밀번호와 같은 수준). 프로필 파일 전체를 예전 백업으로 바꾸는 것도 막지 못함. 1.4.0 → 1.3.0 서버로 내렸다가 다시 올리면, 그 사이 기록은 모드 폴더 사본 시점으로 돌아감.
