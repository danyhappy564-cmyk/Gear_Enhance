## 14. 파괴 방지권 (★★·★★★ 진화, 2026-10-25 사용자)

★★·★★★ 진화는 실패하면 장비가 파괴되고 기존 보호(파괴 방지)를 쓸 수 없습니다. 그래서 진화 전용 **파괴 방지권**을 둡니다.

| | ★★ 진화용 | ★★★ 진화용 |
|---|---|---|
| 장비 하나당 살 수 있는 수 | **최대 3장** | **최대 2장** |
| 1장 가격 (설계자 결정) | **3,000,000 ₽** | **8,000,000 ₽** |

- **한도는 "평생" 기준**: 그 장비에서 산 장수를 세고, 한도까지 사면 다 써도 **더 살 수 없음**(`구매 3 / 3 (더 못 삼)`). 다른 장비는 따로 셈.
- 사는 곳: ★★성·★★★성 탭의 방지권 줄 `1장 구매 · 3,000,000 ₽`. 체크 `방지권 사용 (실패해도 장비 유지)`.
- 쓰는 법 (2026-10-25 사용자 변경): 체크하고 진화 시도 → **성공·실패와 관계없이 시도할 때마다 1장 소모**. 실패하면 장비·단계 그대로(결과 창 `진화 실패 · 파괴 방지권 사용 · 남은 N장`), 성공 결과 창에도 `파괴 방지권 1장 사용 · 남은 N장`.
- **★★용과 ★★★용은 따로**: ★★용 3장 한도는 ★★ 진화에서 끝. ★★ 진화에 성공하면 남은 ★★용은 ★★★로 옮겨지지 않고 **사라짐**(결과 창에 안내, 루블 환불 없음 — 2026-10-25 사용자 확정). ★★★용 2장은 0부터 따로 삼. ★★★ 탭에 `★★용은 못 씀` 표시.
- 방지권을 쓰는 시도는 파괴될 일이 없으므로 12.1의 파괴 확인 창을 띄우지 않음.
- 방지권은 장비에 붙어 있음(장비 ID 기준). 강화 보험 반환·플리마켓·사격장 복사본에서 장비 기록과 함께 따라감. 장비가 다른 이유로 파괴되면(??? 실패 등) 같이 사라짐. 팔거나 다른 장비로 옮길 수 없음.
- 가격 근거: ★★ 진화 비용(최소 200만)의 1.5배, ★★★(400만 고정)의 2배. 성공률이 낮을수록(30% / 10%) 한 장의 가치가 커서 더 비싸게. 시도마다 1장이므로 ★★은 "안전한 3번"에 900만, ★★★은 "안전한 2번"에 1,600만이 추가로 듦. 재료로 성공률을 올리면 그 3번(2번) 안에 성공할 확률이 오름(★★ 재료 최대 60% → 3번 안 성공 약 94%, ★★★ 재료 최대 40% → 2번 안 약 64%).
- 서버 검증: 구매 수·보유 수는 서버 저장값으로만 판단. 견적에 "방지권 사용"이 있으면 보유 1장 이상인지 확인, **시도 영수증마다(성공·실패) 1장 차감**. ★★ 성공 영수증에서 남은 ★★용을 0으로.
- F12 개발자 옵션(잠금): 등급별 최대 장수·가격.
