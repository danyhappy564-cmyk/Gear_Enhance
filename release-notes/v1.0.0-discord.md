## Gear Enhance V 1.0.0

**- 창고에서 총·방어구 능력치를 강화하고 3스타까지 진화시키는 모드 (첫 정식 릴리즈)**

■ 기능
- 무기 3종(반동·조작성·탄 퍼짐), 방어구 2종(내구성·기동성)을 항목마다 +10까지 따로 강화, 효과는 전부 같이 적용
- 성공률 75%에서 단계마다 5%씩 감소, 비용은 장비 가격 비례
- 무기 +5 → +6 도전부터 실패하면 파괴(25%) 또는 그 항목 -1. 파괴 방지·하락 방지 체크로 막을 수 있음(추가 비용)
- 비트코인 + 루블로 성공률 +7~10%
- 전 항목 +10 장비는 스타 진화: 2스타 30%(효과 2배), 3스타 10%(효과 3배). 실패하면 장비 소멸
- 창고에 금색(강화) / 보라(2스타) / 빨간(3스타) 별 표식, 강화 게이지·결과창·전용 효과음

■ 사용법
- 장착 해제한 장비를 창고에 두고 우클릭 → "장비 강화"
- 확률·비용 같은 밸런스는 F12 → "개발자 옵션 표시" 켜고 F12 창을 다시 열면 보임

■ 설치
- zip 풀어서 SPT 폴더에 덮어쓰기. 클라이언트·서버 둘 다 1.0.0으로 맞추고 서버·게임 재시작
- 개발 중 버전을 쓰던 분도 강화 단계·설정 유지

■ 주의
- 보험·플리 미판매로 우편 반환된 장비는 새 아이템 취급이라 강화가 이어지지 않음
- 게임 테스트는 제작자가 완료. 출시 직전 작은 수정 3개는 자동 검사로만 확인. Fika 미지원
