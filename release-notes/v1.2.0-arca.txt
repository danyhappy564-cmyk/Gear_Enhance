Gear Enhance v1.2.0 — 잃어버린 강화 장비를 지켜 주는 강화 보험, 방탄판·내피는 방어구와 한 몸으로

[구분선]

■ 바뀐 것

1) 강화 보험 (새 기능)
- 전에는: 보험 들어 둔 강화 무기를 잃었더니 강화가 풀린 채 돌아왔다는 제보가 있었습니다. 상인 보험은 원래 물건만 돌려주는 장치라 강화를 지켜 주지 못했습니다.
- 이제: 강화 창 위쪽 "보험·방탄판" 버튼(무기는 "강화 보험")을 누르면 강화 보험에 가입할 수 있습니다. 등급은 세 가지입니다.
  일반: 잃었을 때 강화된 채로 돌아올 확률 20%, 보험료는 강화 가치의 5%
  고급: 55%, 보험료 15%
  프리미엄: 90%, 보험료 30%
- 강화 가치는 지금 단계와 별까지 올리는 데 드는 기본 비용을 모두 더한 값입니다. 많이 강화한 장비일수록 보험료가 비쌉니다.
- 레이드에서 죽거나 장비를 두고 나오면, 레이드가 끝날 때 등급 확률로 판정합니다. 성공하면 장비와 거기 달린 부착물·탄창·방탄판이 강화된 그대로 바로 우편으로 옵니다. 같은 장비가 상인 보험으로 한 번 더 오지는 않습니다(이미 낸 상인 보험료는 돌려주지 않습니다). 탄약과 주머니 안 물건은 빠지고, 상인 보험을 들어 뒀다면 그것들만 상인 쪽으로 따로 옵니다.
- 판정에 실패했거나 강화 보험이 없으면 강화는 사라집니다. 상인 보험을 들어 뒀다면 상인이 평소처럼 돌려주지만 강화 안 된 +0 장비입니다.
- 1.1.0과 달라진 점: 1.1.0은 상인 보험으로 돌아온 장비도 강화를 이어 줬지만, 이번부터는 강화 보험만 강화를 지킵니다.
- 보험은 한 번 잃으면 소모됩니다. 강화에 성공하거나 더 비싼 방탄판을 등록하면 보험이 풀려서 다시 가입해야 합니다(싸게 들어 놓고 나중에 강화하는 꼼수 방지). 더 높은 등급으로 바꾸는 건 언제든 됩니다.
- 1.2.0을 깔기 전에 이미 잃어서 상인 보험을 기다리던 장비는 예전처럼 강화가 붙은 채로 돌아옵니다.
- 확률과 보험료는 F12 개발자 옵션 "12. 강화 보험"에 있습니다(개발자 옵션은 이번부터 비밀번호로 잠겼습니다. 아래 5번).
- 확인: 자동 검사로만 확인했고, 실제 레이드에서 죽은 뒤 우편이 오는지는 아직 게임에서 확인 못 했습니다.

2) 방탄판·내피·바이저는 방어구와 함께 강화 (바뀐 것)
- 전에는: 방탄판 일부를 따로 강화할 수 있어서, 1강 방어구에 4강 방탄판처럼 단계가 엇갈렸습니다.
- 이제: 방어구에 끼운 방탄판, 내피, 헬멧에 다는 바이저 같은 부품은 그 방어구의 강화(내구성·기동성)를 같이 받고, 창고에서도 방어구와 같은 별 표식이 붙습니다. 빼서 주머니나 가방에 넣으면 적용되지 않습니다.
- 부품은 따로 강화할 수 없습니다. 방탄판·내피·바이저를 우클릭하면 "장비 강화"가 아예 뜨지 않습니다.
- 예전에 따로 강화해 둔 방탄판은 기록은 남겨 두지만 효과와 별 표식은 없어집니다. 방어구에 끼우면 그 방어구의 단계를 씁니다. 바이저를 따로 강화해 두셨다면 그 효과도 같이 사라집니다.
- 비용: 방어구 강화 비용은 "방어구 본체 + 끼운 방탄판" 가격으로 계산합니다. 무기는 지금처럼 본체만 봅니다.
- 등록: 방어구를 강화할 때(성공이든 실패든, 파괴 제외) 끼워져 있던 방탄판만 효과를 받습니다. 싼 방탄판으로 싸게 강화하고 비싼 방탄판으로 바꿔 끼우는 걸 막으려고 이렇게 했습니다. 새 방탄판은 "보험·방탄판" 창에서 등록하면 바로 적용됩니다.
- 방탄판 차액: 더 비싼 방탄판으로 바꾸면 이미 올린 단계만큼 가격 차이를 한 번 냅니다. 다음 강화 비용에 붙거나 "방탄판 등록" 버튼으로 따로 냅니다. 같은 값이나 더 싼 방탄판은 무료로 등록됩니다.
- 1.2.0 전에 강화한 방어구는 업데이트 뒤 처음 볼 때 끼워져 있던 방탄판을 무료로 등록해 줍니다.
- 확인: 아직 게임에서 확인 못 했습니다. 방탄판 별 표식과 우클릭 메뉴가 이상하면 스크린샷 부탁드립니다.

3) 보험으로 돌아온 장비 기록 보강 (고친 것)
- 제보를 따라가 보니, 1.1.0 서버가 제대로 깔려 있으면 기록이 이어지는 구조였습니다. 강화가 사라진 경우는 두 가지였습니다. 하나는 1.0.0을 쓰던 때 장비를 잃고 그 사이에 강화 창을 연 경우(1.0.0이 창고에 없는 장비 기록을 지웠습니다), 다른 하나는 게임 쪽만 새 버전으로 바꾸고 서버 쪽은 1.0.0으로 남은 경우(겉으로는 멀쩡히 동작했습니다)입니다.
- 이제: 앞의 경우는 장비가 돌아올 때 최근 강화 결과 100건을 보고 그 장비의 단계와 별을 되살립니다. 뒤의 경우는 한쪽만 1.2.0이면 강화 창이 "둘 다 업데이트해 주세요" 안내를 띄우고 멈춥니다. 저장된 강화 기록은 지우지 않습니다.
- 서버 창에 "보험·플리 반환 장비 강화 기록 연결 준비 완료" 한 줄이 보이면 서버 쪽도 제대로 올라간 것입니다.

4) 화면과 영어
- 오른쪽 클릭 메뉴는 늘어나지 않습니다. 지금처럼 "장비 강화" 한 줄만 있고, 보험과 방탄판 등록은 강화 창 안에서 합니다.
- 강화 창 맨 위 줄에 지금 들어 있는 강화 보험이 보입니다(예: 강화 보험 고급 55%).
- 글씨에 색을 넣었습니다. 일반 등급은 연두, 고급은 파랑, 프리미엄은 주황빛 금색입니다. 초록은 좋은 소식(강화된 채 반환, 모두 등록됨), 주황은 주의(미등록 방탄판, 보험 소모, 방탄판 차액), 빨강은 손해(상인 보험은 +0, 강화 소멸)입니다.
- 영어 문구를 처음부터 끝까지 다시 다듬었습니다. 어색한 표현을 고치고, 칸을 넘칠 수 있는 긴 문장은 줄였습니다.

5) F12 개발자 옵션 비밀번호 잠금 (바뀐 것)
- 전에는: F12에서 "개발자 옵션 표시"만 켜면 누구나 "항상 성공", 확률, 비용 같은 밸런스를 바꿀 수 있었습니다.
- 이제: "99. 개발자 옵션" 안의 "개발자 옵션 비밀번호" 칸에 제작자 비밀번호를 넣어야 개발자 옵션이 보이고 적용됩니다. 입력한 글자는 별표로 가려지고, 옆에 잠김 또는 열림이 표시됩니다.
- 잠겨 있으면 숨기기만 하는 게 아니라 기본 밸런스로 강화합니다. 예전에 "항상 성공" 같은 걸 켜 뒀거나 설정 파일을 직접 고쳤어도 적용되지 않습니다. 바꿔 둔 값은 지우지 않으니 나중에 열면 그대로 돌아옵니다.
- 예전의 "개발자 옵션 표시" 체크는 없어졌습니다.
- 비밀번호는 공개하지 않습니다. 모드 코드에도 비밀번호 자체는 들어 있지 않습니다.

6) 기타
- 강화 확률과 효과 수치는 1.1.0과 같습니다. 방어구 비용에 끼운 방탄판 가격이 더해지는 것만 다릅니다.
- 자동 검사 230개가 모두 통과했습니다.

■ 알아 두실 점

- 아직 게임에서 확인 못 한 것: 실제로 죽은 뒤 강화 보험 우편, 상인 보험 +0 반환, 보험 창 배치와 색, 영어 글자 잘림, 방탄판 별 표식.
- 1.1.0으로 되돌리면 강화 보험 가입과 방탄판 등록 정보가 사라집니다. 강화 단계와 별은 남습니다. 다시 1.2.0으로 올리면 방탄판은 무료로 다시 등록되지만 보험은 다시 들어야 합니다. 되돌릴 때는 게임 쪽과 서버 쪽을 둘 다 1.1.0으로 맞춰 주세요.
- 상인에게 판 장비는 지금도 강화가 이어지지 않습니다. 여러 명이 같이 하는 환경(Fika)은 지원하지 않습니다.

■ 설치

GearEnhance-1.2.0.zip 을 풀어서 SPT 폴더에 덮어쓰기 하면 됩니다. 게임 쪽과 서버 쪽이 한 압축 파일에 같이 들어 있으니 둘 다 1.2.0으로 바꾸고 서버와 게임을 다시 켜 주세요. 한쪽만 바꾸면 강화 창이 업데이트 안내를 띄웁니다. 강화 단계, 진화 기록, 설정은 그대로 남습니다.

■ 버그 제보

스크린샷 + BepInEx/LogOutput.log 같이 주시면 빨리 봅니다. 강화 보험 관련이면 어떤 등급이었는지, 죽었는지 두고 나왔는지, 서버 창에 "강화 보험으로 반환" 줄이 나왔는지도 알려 주세요.
