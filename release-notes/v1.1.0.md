# Gear_Enhance v1.1.0

**태그:** `1.1.0` (main `6925805`)

**이전 릴리즈:** v1.0.0 (GitHub 릴리즈 `1.0.0`, 그 뒤 커밋 6개) → **이번: v1.1.0** (기능 추가 + 버그 수정)

**<변경점>**

**1. 한국어 / 영어 전환 추가 (F12 `0. Language · 언어`)**
- 1.0.0은 모든 화면이 한국어뿐이라 외국 사용자는 쓰기 어려웠습니다.
- F12 맨 위 `Language · 언어`에서 `Auto`(기본) / `Korean` / `English`를 고릅니다. `Auto`는 윈도우 표시 언어가 한국어면 한국어, 그 밖에는 영어입니다.
- 바뀌는 곳: 강화 창, 스타 진화 창, 결과 창, 우클릭 메뉴(`Enhance gear`), 창고 표식(별 두 개 + `Evolved +30`), 서버 오류 안내, F12 설정 이름·분류·설명.
- 열려 있는 강화 창은 바로 바뀌고, 창 아래 안내 한 줄은 다음 안내부터 바뀝니다. F12 설정 글자는 F12 창을 닫았다 다시 열면 바뀝니다(설정 관리자가 창을 열 때 글자를 다시 읽음).
- 설정 파일(`rf.gearenhance.cfg`)의 키 이름은 예전 한국어 그대로라 언어를 바꿔도, 1.0.0에서 올려도 설정값이 초기화되지 않습니다.
- 서버 오류 문구는 서버가 한국어·영어를 함께 보내고 클라이언트가 고른 언어로 보여 줍니다. `LogOutput.log` 진단 문구와 서버 로그는 한국어 그대로입니다.
- 확인 상태: 빌드·자동 검사만 확인, 게임 미검증. 영어 문장이 칸 밖으로 잘리는지는 비슷한 글꼴로 폭만 재 봤습니다.

**2. 보험·플리마켓으로 돌아온 장비의 강화 기록 유지**
- 1.0.0에서는 보험으로 돌려받은 장비, 플리마켓에서 안 팔려 만료되거나 직접 내려서 우편으로 돌아온 장비가 강화 안 된 새 장비처럼 돌아왔습니다(1.0.0 "알려진 점").
- 원인: SPT 서버가 우편을 보낼 때 첨부 장비를 복제하면서 아이템 ID를 전부 새로 붙입니다. 강화 기록은 옛 ID에 묶여 있어서 연결이 끊겼습니다.
- 고친 것: 서버가 우편을 보내는 순간 옛 ID와 새 ID 짝을 받아, 항목별 강화 단계와 2스타/3스타 진화를 새 장비로 옮깁니다. 개수·순서·아이템 종류가 정확히 맞을 때만 옮기고, 지금 갖고 있는 장비를 복사한 우편에는 옮기지 않습니다(기록이 둘로 늘어나지 않게).
- 아직 돌아오지 않은 장비(보험 대기 중, 플리에 올려 둔 것, 우편함에 있는 것)는 창고에 없어도 기록을 지우지 않습니다. 1.0.0은 창고에 없는 장비 기록을 정리 대상으로 봤습니다.
- 우편에서 장비를 꺼내면, 클라이언트가 처음 보는 장비를 발견했을 때 레이드 밖에서 5초 간격으로 서버 기록을 다시 받아 몇 초 안에 표식과 능력치가 붙습니다.
- 확인 상태: 실제 SPT 4.1.6의 ID 교체 함수로 보험·플리 반환을 흉내 낸 검사에서 3개 항목 단계와 3스타가 새 ID로 이어졌고, 서버 패치가 실제 우편 함수에 걸리는 것을 테스트 환경에서 확인했습니다. 게임 안 실제 보험·플리 반환은 미검증입니다.

**3. 기타**
- 저장소에 모드 아이콘(`assets/icon.png`, 원본 `icon.svg`)을 추가했습니다. 게임 동작과는 무관합니다.
- README의 혼용 설명을 바로잡았습니다: 1.0.0과 1.1.0은 통신 버전(7)이 같아 섞어 써도 강화는 되지만, 반환 기록 연결·영어 오류 문구는 양쪽 다 1.1.0이어야 동작합니다.
- Release 클린 빌드 경고 0·오류 0, 자동 검사 211개 통과(서버 151 / 클라이언트 60, 실제 게임 DLL 대조 포함). 1.0.0 대비 강화 확률·비용·효과 수치는 바뀌지 않았습니다.

**알려진 점**
- 1.0.0 이하에서 이미 돌려받은 장비의 기록은 지워진 상태라 되살릴 수 없습니다. 1.1.0 설치 후 새로 잃거나 플리에 올린 장비부터 적용됩니다.
- 상인에게 판 장비는 지금도 기록이 이어지지 않습니다(다시 사도 다른 아이템).
- 보험 상인이 부착물 일부를 돌려주지 않으면 돌아온 부분만 받습니다. 강화 기록은 돌아온 본체에 이어집니다.
- 영어로 바꿨는데 일부 글자가 한국어로 남으면 강화 창·F12 창을 닫았다 다시 열어 주세요.
- Fika·다중 사용자 환경은 지원 범위가 아닙니다.
- 이상하면 F12 `Language · 언어`를 `Korean`으로 두거나 1.0.0 zip으로 되돌릴 수 있습니다. 저장 형식은 그대로라 창고에 있는 장비 기록은 남지만, 1.0.0으로 되돌린 동안에는 보험 대기·플리 판매 중인 장비 기록이 예전처럼 정리될 수 있습니다.

**설치 / 업데이트**

**<Changes (English)>**

**1. Korean / English switch (F12 `0. Language · 언어`)**
- 1.0.0 was Korean only.
- Pick `Auto` (default) / `Korean` / `English` at the top of F12. `Auto` uses Korean when Windows is set to Korean, otherwise English.
- Covers the enhance window, star evolution window, result panel, right-click menu (`Enhance gear`), stash badges (two stars + `Evolved +30`), server error messages, and F12 setting names, sections and descriptions.
- The open window switches at once; its bottom hint line switches with the next hint. F12 texts update after you close and reopen the F12 window.
- Config keys in `rf.gearenhance.cfg` stay the same, so switching language or updating from 1.0.0 does not reset your settings.
- The server sends error messages in both languages and the client shows the selected one. `LogOutput.log` diagnostics and server logs stay in Korean.
- Status: build and automated tests only, not tested in game. Text widths in English were only estimated with a similar font.

**2. Enhancement kept on gear returned by insurance or the flea market**
- In 1.0.0, gear returned by insurance, or by expired/cancelled flea offers through mail, came back unenhanced (listed under 1.0.0 known issues).
- Cause: when SPT sends mail it clones the attached items and gives them all new item IDs, while enhancement records were tied to the old IDs.
- Fix: the server captures the old-to-new ID pairs when the mail is sent and moves per-stat levels and 2-star/3-star evolution to the new item. It only moves records when count, order and item type match exactly, and never for mail that copies gear you still own (so a record is never duplicated).
- Records of gear that has not come back yet (pending insurance, active flea offers, mail attachments) are no longer cleaned up while the item is missing from your stash.
- When you take gear out of the mail, the client notices the new item and re-syncs records outside raids (at most every 5 seconds), so badges and stats appear within a few seconds.
- Status: a test using SPT 4.1.6's real ID replacement kept three stat levels and 3-star evolution on the new IDs, and the server patch attaches to the real mail method in a test host. Not yet tested with real insurance/flea returns in game.

**3. Other**
- Added a mod icon to the repository (`assets/icon.png`, source `icon.svg`). No gameplay effect.
- Corrected the README on mixing versions: 1.0.0 and 1.1.0 share protocol 7 and can be mixed, but return record transfer and English server errors need 1.1.0 on both sides.
- Clean Release build with 0 warnings / 0 errors, 211 automated tests passing (server 151 / client 60, including checks against real game DLLs). Chances, costs and effect values are unchanged from 1.0.0.

**Known issues**
- Gear already returned under 1.0.0 or earlier lost its record and cannot be restored. Only gear lost or listed after installing 1.1.0 is covered.
- Gear sold to traders still does not keep its record.
- If insurance does not return some attachments, only the returned parts come back; the record stays on the returned base item.
- If some text stays in Korean after switching to English, close and reopen the enhance window or the F12 window.
- Fika/multiplayer is not supported.
- If something looks wrong, set F12 `Language · 언어` to `Korean` or roll back to the 1.0.0 zip. The save format is unchanged, so records of gear in your stash stay, but while on 1.0.0 records of gear pending insurance or listed on the flea may be cleaned up as before.

**Install / update**
- Extract `GearEnhance-1.1.0.zip` into your SPT folder and overwrite (`BepInEx\plugins\GearEnhance` + `SPT_Runtime\user\mods\GearEnhance`).
- Update both client and server to 1.1.0 and restart the server and the game. Levels, evolutions and settings are kept.
