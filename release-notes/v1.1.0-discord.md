## Gear Enhance V 1.1.0

**- 영어 화면 추가 + 보험·플리마켓으로 돌아온 장비도 강화가 그대로**

■ 바뀐 것
- 한/영 전환: F12 맨 위 "Language · 언어"에서 Auto / Korean / English. Auto는 윈도우가 한국어면 한국어. 강화·진화·결과 창, 우클릭 메뉴, 별 표식, 오류 안내, F12 설정까지 바뀜. F12 글자는 F12 창을 다시 열어야 바뀜. 설정값 유지 (게임 미확인)
- 보험으로 돌려받거나 플리에서 안 팔려(내려서) 우편으로 돌아온 장비가 강화 없는 새 장비로 돌아오던 문제 수정. 우편 보낼 때 새 이름표가 붙어 기록이 끊기던 게 원인이라, 그 순간 기록을 새 장비로 옮김. 보험 대기·플리 판매 중·우편함에 있는 동안엔 기록 안 지움. 꺼내면 몇 초 안에 표식·능력치가 붙음 (검사로 확인, 실제 반환은 게임 미확인)
- 기타: 모드 아이콘 추가. 확률·비용·효과 수치는 1.0.0과 같음

■ 설치
- GearEnhance-1.1.0.zip 풀어서 SPT 폴더에 덮어쓰기. 클라이언트·서버 둘 다 1.1.0으로 맞추고 서버·게임 재시작 (강화 기록·설정 유지)

■ 주의
- 1.0.0 이하에서 이미 돌려받아 강화가 사라진 장비는 되살릴 수 없음. 1.1.0 설치 후 잃거나 올린 장비부터 적용
- 상인에게 판 장비는 여전히 안 이어짐. Fika 미지원
- 영어 글자가 칸 밖으로 잘리면 스크린샷 부탁드립니다
