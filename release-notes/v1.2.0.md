# Gear_Enhance v1.2.0

**태그:** `1.2.0` (코드 기준 main `b9a4fe1`, 그 위 릴리즈 노트 커밋에 태그해도 코드는 같음)

**이전 릴리즈:** v1.1.0 (GitHub 릴리즈 `1.1.0`, 그 뒤 코드 커밋 4개) → **이번: v1.2.0** (기능 추가 + 제보 대응)

**<변경점>**

**1. 강화 보험 추가 (일반 20% · 고급 55% · 프리미엄 90%)**
- 제보: "보험 넣은 강화 무기를 잃었더니 강화가 풀려서 돌아왔다." 상인 보험은 원래 강화를 지키는 장치가 아니라서, 강화를 지키는 보험을 따로 만들었습니다.
- 강화 창 위쪽 `보험·방탄판` 버튼(무기는 `강화 보험`)에서 등급을 골라 가입합니다.

| 등급 | 레이드에서 잃었을 때 강화된 채 돌아올 확률 | 보험료(강화 가치 대비) |
|---|---|---|
| 일반 | 20% | 5% |
| 고급 | 55% | 15% |
| 프리미엄 | 90% | 30% |

- **강화 가치** = 지금 단계·스타까지 강화하는 데 드는 기본 비용의 합(방어구는 등록한 방탄판 가격 포함, 2스타 진화비·3스타 400만 포함). 많이 강화할수록 보험료가 오릅니다. 1회 최대 1억 루블.
- 레이드가 끝났을 때 강화 장비가 없어졌으면(사망·두고 나옴) 등급 확률로 판정합니다. 성공하면 장비와 슬롯 부품(부착물·탄창·방탄판)이 강화·스타·방탄판 등록 그대로 **바로 우편**으로 옵니다(탄약·주머니 안 물건 제외). 그 장비의 상인 보험 반환은 빠져서 두 개가 되지 않습니다(이미 낸 상인 보험료는 돌려주지 않음).
- **판정에 실패했거나 강화 보험이 없으면 강화는 사라집니다.** 상인 보험이 있으면 상인이 평소대로 돌려주지만 +0 장비입니다. **1.1.0과 다른 점:** 1.1.0은 상인 보험 반환에도 강화를 이어 줬지만, 1.2.0부터는 강화 보험만 강화를 지킵니다.
- 보험은 한 번 잃으면 소모됩니다. 강화에 성공하거나 더 비싼 방탄판을 등록하면 강화 가치가 바뀌어 보험이 풀립니다(싸게 들어 두고 나중에 강화하는 것을 막기 위해). 같은 등급 이상은 다시 살 수 없고, 더 높은 등급으로는 바꿀 수 있습니다(새 등급 보험료 전액).
- 1.2.0을 설치하기 전에 이미 잃어서 상인 보험 대기 중인 장비는 예전(1.1.0) 방식대로 강화를 유지한 채 돌아옵니다.
- 확률·보험료는 F12 개발자 옵션 `12. 강화 보험`에 있습니다(개발자 옵션은 이번부터 비밀번호로 잠김, 5번 참고). 확률은 가입할 때 값으로 고정됩니다.
- 확인 상태: 실제 SPT 레이드 종료 함수에 패치가 걸리는 것과 반환·소멸·상인 중복 제거를 검사로 확인했습니다. 실제 레이드 사망 후 반환 우편은 게임 미검증입니다.

**2. 방탄판·내피·바이저는 방어구와 함께 강화 (따로 강화 폐지)**
- 1.1.0까지는 방탄판 일부만 따로 강화돼, 방어구와 방탄판 단계가 엇갈렸습니다("1강 방어구에 4강 방탄판").
- 이제 방어구에 끼운 방탄판·내피(소프트 삽입물)·헬멧 부착 방호구(바이저 등)는 **그 방어구의 내구성·기동성 강화를 함께 받고**, 창고·검사 화면에도 방어구와 같은 별 표식이 붙습니다. 빼서 주머니·가방에 넣으면 적용되지 않습니다.
- **이 부품들은 따로 강화할 수 없습니다.** 우클릭 메뉴에 `장비 강화`가 뜨지 않고, 서버도 강화·보험·등록을 거절합니다.
- 1.2.0 전에 따로 강화해 둔 부품은 기록은 지우지 않지만 효과·표식은 없습니다. 방어구에 끼우면 그 방어구의 단계만 씁니다. 헬멧 바이저를 따로 강화해 두셨다면 그 효과도 같이 사라집니다.
- **비용:** 방어구의 강화·진화 비용은 `본체 + 지금 끼운 부품` 가격으로 계산합니다(무기는 지금처럼 본체만). 가격 줄에 `본체+방탄판`이 보입니다.
- **등록:** 효과는 방어구를 강화(성공·실패 모두, 파괴 제외)하거나 `보험·방탄판` 창에서 등록할 때 끼워져 있던 부품만 받습니다. 싼 방탄판으로 싸게 강화한 뒤 비싼 방탄판으로 바꿔 끼우는 것을 막기 위해서입니다. 한 번 등록한 방탄판은 빼었다 다시 끼워도 다시 받습니다.
- **방탄판 차액:** 지금 끼운 부품이 지금까지 값을 치른 부품보다 비싸면, 이미 올린 단계마다(2스타 진화분 포함) 그 가격 차이만큼을 한 번 냅니다. 다음 강화 비용에 붙거나 `방탄판 등록` 버튼으로 따로 냅니다. 같거나 싼 방탄판은 무료로 등록됩니다.
- 1.2.0 전에 강화한 방어구는 업데이트 후 처음 볼 때 끼워져 있던 부품을 무료로 등록합니다.
- 확인 상태: 실제 게임 DLL에서 방탄판 칸이 "슬롯"이고 주머니는 슬롯이 아님을 대조했습니다. 게임 안 별 표식와 우클릭 메뉴 빠짐은 미검증입니다.

**3. 보험 반환 기록 보강 + 버전 섞임 차단**
- 제보 조사 결과, 1.1.0 서버가 깔려 있으면 반환 기록이 이어지는 구조였습니다. 강화가 사라진 경우는 (가) 1.0.0을 쓰던 때 잃고 그 사이 강화 창을 연 경우(1.0.0이 창고에 없는 장비 기록을 지움), (나) 클라이언트만 바꾸고 서버가 1.0.0이던 경우(통신 버전이 같아 조용히 동작)였습니다.
- (가): 반환될 때 최근 강화 결과 100건으로 그 장비의 항목별 단계·스타를 되살립니다. 파괴되거나 0단계가 된 장비는 되살리지 않습니다.
- (나): 통신 버전을 8로 올려, 한쪽만 1.2.0이면 강화 창이 "클라이언트와 서버를 모두 1.2.0으로 업데이트해 주세요" 안내를 띄우고 멈춥니다. 저장된 기록은 지우지 않습니다.
- 서버 시작 로그에 `Gear Enhance 1.2.0: 보험·플리 반환 장비 강화 기록 연결 준비 완료` 한 줄이 나오면 서버 쪽이 제대로 올라간 것입니다.

**4. 화면 · 영어**
- `보험·방탄판` 창 추가(강화 창 위에 겹쳐 뜸). 우클릭 메뉴는 늘어나지 않고 `장비 강화` 한 줄 그대로입니다. 강화 창 크기도 그대로입니다.
- 강화 창 머리줄에 지금 가입한 강화 보험이 등급 색으로 보입니다(`강화 보험 고급 55%` / `강화 보험 없음`).
- 글씨 색: 일반 = 연두, 고급 = 파랑, 프리미엄 = 주황빛 금색. 초록 = 좋은 결과(강화된 채 반환·모두 등록됨), 주황 = 주의(미등록 방탄판·보험 소모·방탄판 차액), 빨강 = 손실(상인 보험은 +0·강화 소멸).
- 영어 문구를 전부 다시 검수했습니다(어색한 표현 정리, 칸을 넘을 수 있는 긴 문구 줄임). 예: `Enhance failed` → `Enhancement failed`, `Same or higher tier already bought` → `Already insured at this tier or higher`.

**5. F12 개발자 옵션 비밀번호 잠금**
- 1.1.0까지는 F12에서 `개발자 옵션 표시`만 켜면 누구나 `항상 성공`, 확률, 비용 같은 밸런스를 바꿀 수 있었습니다.
- 이제 `99. 개발자 옵션 → 개발자 옵션 비밀번호` 칸에 제작자 비밀번호를 넣어야 개발자 옵션이 보이고 적용됩니다. 입력은 `*`로 가려지고 옆에 `잠김`/`열림`이 표시됩니다.
- **잠겨 있으면 숨기기만 하는 게 아니라 기본 밸런스로 강화합니다.** 예전에 바꿔 둔 값이나 설정 파일을 직접 고친 값도 적용되지 않습니다. 저장값은 지우지 않아 다시 열면 돌아옵니다.
- 코드에는 비밀번호 원문이 없고 해시(되돌릴 수 없는 암호값)만 있습니다. 공개 저장소라 코드를 고쳐 다시 빌드하면 풀 수 있으니, F12에서 쉽게 바꾸는 것을 막는 장치로 봐 주세요.
- 1.1.0 이하의 `개발자 옵션 표시` 체크는 없어졌습니다(설정 파일에 남아도 무시).

**6. 기타**
- Release 클린 빌드 경고 0·오류 0, 자동 검사 230개 통과(서버 164 / 클라이언트 66, 실제 게임·SPT DLL 대조 포함).
- 강화 확률·비용 공식·효과 수치는 1.1.0과 같습니다(방어구 비용에 끼운 방탄판 가격이 더해지는 것만 다름).

**알려진 점**
- 게임 안 확인 전입니다: 실제 사망 후 강화 보험 반환 우편, 상인 보험 +0 반환, `보험·방탄판` 창 배치·색·영어 글자 잘림, 방탄판 별 표식, 방탄판 우클릭 메뉴 빠짐.

**<Changes (English)>**

**1. Enhancement insurance (Basic 20% · Advanced 55% · Premium 90%)**
- Report: "My insured enhanced weapon came back unenhanced." Trader insurance was never meant to keep enhancements, so a separate insurance now does.
- Buy it from the `Insure · plates` button at the top of the enhance window (`Insure` for weapons).

| Tier | Chance lost gear is returned still enhanced | Fee (of enhancement value) |
|---|---|---|
| Basic | 20% | 5% |
| Advanced | 55% | 15% |
| Premium | 90% | 30% |

- **Enhancement value** = the base cost of reaching the current levels and stars (armor includes its registered plates, 2nd star evolution cost and the 4,000,000 ₽ 3rd star included). More enhancement means a higher fee. Max 100,000,000 roubles per purchase.
- If enhanced gear is missing when a raid ends (death or left behind), the tier's chance is rolled. On success the gear and its slot parts (attachments, magazines, plates) are mailed back **at once** with levels, stars and plate registration kept (ammo and pocket contents excluded). That gear's trader insurance return is removed so you never get two (the trader fee is not refunded).
- **If the roll fails or the gear is not insured, the enhancement is lost.** Trader insurance still returns it as usual, at +0. **Change from 1.1.0:** 1.1.0 kept enhancements on trader insurance returns; from 1.2.0 only enhancement insurance keeps them.
- Coverage is used up after one loss. A successful upgrade or registering pricier plates changes the value and ends coverage. The same or a lower tier cannot be bought again; a higher tier can (full fee of the new tier).
- Gear already lost and waiting for trader insurance before installing 1.2.0 still comes back enhanced, the 1.1.0 way.
- Chances and fees are in F12 developer options `12. Enhancement insurance` (developer options are now password-locked, see 5). The chance is locked in when the insurance is bought.
- Status: tests confirm the patch attaches to SPT's real raid-end method and cover return, loss and trader de-duplication. Not yet tested with a real death in game.

**2. Plates, inserts and visors are enhanced with their armor (no longer alone)**
- Up to 1.1.0 some plates could be enhanced alone, so armor and plate levels could differ ("+1 armor with a +4 plate").
- Plates, soft inserts and helmet add-ons (visors etc.) inside an armor now **share its durability and mobility enhancement** and show the same star badge. Moved to a pocket or backpack, they do not.
- **They cannot be enhanced alone.** The right-click menu has no `Enhance gear` for them and the server refuses enhancing, insuring or registering them.
- Parts enhanced alone before 1.2.0 keep their record but get no effect or badge; inside an armor they use the armor's level. A helmet visor enhanced alone loses its effect too.
- **Cost:** armor enhancement and evolution are priced on `body + inserted parts` (weapons still use the body only).
- **Registration:** only parts inserted when the armor is enhanced (success or failure, not destruction) or registered in the `Insure · plates` window get the effect. This stops enhancing cheaply with cheap plates and swapping in expensive ones. A registered plate gets it again after being taken out and put back.
- **Plate fee:** if the inserted parts are worth more than the ones paid for, the price difference is charged once for every level already gained (2nd star included), either with the next upgrade or via `Register plates`. The same or cheaper plates register for free.
- Armor enhanced before 1.2.0 registers the parts it holds for free the first time it is seen.
- Status: checked against the real game DLL that plate slots are slots and pockets are not. The star badge and the missing menu entry are not yet tested in game.

**3. Stronger insurance return records + version mix blocked**
- The 1.1.0 server already keeps records on returns. Enhancements were lost when (a) gear was lost under 1.0.0 and the enhance window was opened meanwhile (1.0.0 removed records of gear not in the stash), or (b) only the client was updated and the server stayed on 1.0.0 (same protocol, so it ran silently).
- (a): on return, the item's per-track levels and stars are rebuilt from the last 100 enhancement results. Destroyed or level-0 gear is not restored.
- (b): protocol version is now 8; if only one side is 1.2.0 the window says to update both and stops. Saved records are not deleted.
- The server log shows one line `Gear Enhance 1.2.0: ... Insurance/flea return records hook ready.` when the server side loaded.

**4. UI · English**
- New `Insure · plates` window drawn over the enhance window. The right-click menu still has just one `Enhance gear` line and the window size is unchanged.
- The window header shows the current enhancement insurance in its tier color (`Insured: Advanced 55%` / `Not insured`).
- Text colors: Basic = light green, Advanced = blue, Premium = amber gold. Green = good (returned enhanced, all registered), orange = caution (unregistered plates, coverage used up, plate fee), red = loss (trader insurance returns +0, enhancement lost).
- All English text was reviewed again (awkward wording fixed, long lines that could overflow shortened).

**5. F12 developer options password lock**
- Up to 1.1.0 anyone could turn on `Show developer options` in F12 and change `Always succeed`, chances, costs and the rest of the balance.
- Developer options now show and apply only after the author's password is entered in `99. Developer options → Developer options password`. The field is masked with `*` and shows `Locked`/`Unlocked` beside it.
- **While locked, enhancing uses the default balance**, not just hidden settings: values changed earlier or edited in the config file do not apply. Saved values are kept and come back when unlocked.
- Only a hash of the password is in the code, never the password. The repository is public, so rebuilding the mod can bypass it; it stops casual F12 changes.
- The old `Show developer options` toggle is gone (ignored if still in the config file).

**6. Other**
- Clean Release build with 0 warnings / 0 errors, 230 automated tests passing (server 164 / client 66, including checks against real game and SPT DLLs).
- Chances, cost formula and effect values are the same as 1.1.0 (only armor cost now adds inserted plates).

**Known issues**
- Not yet tested in game: insurance return mail after a real death, trader +0 return, the `Insure · plates` window layout/colors/English clipping, plate star badges, the missing plate menu entry.
- Rolling back to 1.1.0 drops enhancement insurance and plate registration (levels and stars stay). Coming back to 1.2.0 registers plates again for free, but insurance must be bought again. Roll back both client and server together.
- Gear sold to traders still does not keep its record. Fika/multiplayer is not supported.

**Install / update**
- Extract `GearEnhance-1.2.0.zip` into your SPT folder and overwrite (`BepInEx\plugins\GearEnhance` + `SPT_Runtime\user\mods\GearEnhance`).
- Update **both client and server to 1.2.0** and restart the server and the game. Levels, evolutions and settings are kept.
