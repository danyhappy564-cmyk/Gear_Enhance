## Gear Enhance V 1.3.0

**- 초월 강화 + 강화 보험 + 방탄판은 방어구와 함께 강화 (1.1.0 다음 공개판)**

■ 바뀐 것
- 초월 강화: 별 2개 이상 장비에 2성·3성 초월(각 0~5단계). 총 2성 수평 반동 -30%, 3성 발사속도 약 +30%(단발 총은 고장·과열 감소). 방어구 2성 최대 내구도 +30%, 3성 둔탁상 감소·방어등급 최대 +2. 실패해도 파괴 없음, 4·5단계만 하락. 돈+재료 필요 (발사속도 게임 확인: 968 vs 748rpm)
- 강화 보험: 강화 창 "보험·방탄판"에서 가입. 잃었을 때 강화된 채 돌아올 확률 일반 20%·고급 55%·프리미엄 90%, 장비마다 따로 판정. 보험 없는 장비는 강화 소멸(상인 보험은 +0으로 돌려줌) (게임 확인)
- 방탄판·내피·바이저: 방어구 강화·초월을 같이 받고 따로 강화는 불가. 값을 치른 방탄판 이하면 새것·헌것 상관없이 끼우는 즉시 무료 적용, 더 비싼 것만 차액
- 화면: 강화 창 위 상태 띠(보험 등급·확률, 초월 단계, 별), 창고·장비칸 보험 배지(P·고·일·X), 가입 때 보험 소리
- 은신처 사격장에서도 강화·초월 효과 적용(전엔 전부 빠져 있었음)
- F12 개발자 옵션은 비밀번호 잠금

■ 설치
- GearEnhance-1.3.0.zip 풀어서 SPT 폴더에 덮어쓰기. 클라이언트·서버 둘 다 1.3.0, 서버·게임 재시작 (기록·설정 유지)

■ 주의

- 1.1.0으로 되돌리면 보험·방탄판·초월 정보가 사라짐(단계·별은 유지). Fika 미지원
