Gear Enhance v1.4.1 — 러시아어·중국어 추가, 창고 보험 표시 설정

===== 여기부터 본문 — 복사해서 붙여넣기. [대괄호]는 직접 바꾸는 자리 =====

[대표 이미지]

Gear Enhance v1.4.1 — 러시아어·중국어를 넣고, 거슬리던 창고 보험 표시를 바꾸거나 끌 수 있게 했습니다

SPT 4.1.6용 무기·방어구 강화 모드입니다. 1.4.0을 올린 뒤 해외 유저분들께 받은 의견 두 가지(러시아어 번역 요청, 보험 아이콘이 거슬린다는 의견)를 반영한 업데이트입니다.

[구분선]

■ 바뀐 것

1) 러시아어·중국어(간체)를 추가했습니다

- 이제: 강화 창 위쪽 언어 버튼이 한국어 · EN · RU · 中文 4개가 됩니다. 누르면 강화 창, 오른쪽 장비 상태, 결과 팝업까지 그 자리에서 바로 바뀝니다. F12의 "Language · 언어"에도 Russian, Chinese가 생겼습니다.
- 자동 선택: 기본값(Auto)은 윈도우 언어를 보고 고릅니다. 한국어 윈도우는 한국어, 러시아어·우크라이나어·벨라루스어는 러시아어, 중국어는 중국어, 나머지는 영어입니다.
- 범위: 강화 창 전체, 결과 팝업, 창고 표식, F12 일반 설정, 서버에서 오는 오류 안내까지 바뀝니다. 비밀번호로 여는 개발자 옵션만 영어로 둡니다.
- 중국어 글꼴: 모드에 들어 있는 글꼴에는 한자가 없어서, 중국어를 고르면 강화 창 글꼴이 윈도우에 기본으로 깔린 중국어 글꼴로 바뀝니다.
- 확인: 게임에서 네 가지 언어 전환과 중국어 글자가 제대로 나오는 것을 확인했습니다. 러시아어·중국어 문장은 아직 원어민이 봐 주지 않아서 어색한 곳이 있을 수 있습니다.

[GIF 1: 언어 전환 — 강화 창 위 버튼으로 한국어 → 영어 → 러시아어 → 중국어로 바뀌는 모습. 오른쪽 장비 상태 칸도 같이 바뀝니다]

2) 번역 파일을 직접 고치거나 새 언어를 만들 수 있습니다

- 어디: 모드 폴더 안 lang 폴더에 러시아어(ru.tsv), 중국어(zh.tsv), 빈 번역틀(template.tsv) 파일이 들어 있습니다. 엑셀이나 구글 시트, 메모장으로 열 수 있는 표이고, 칸은 한국어 원문 / 영어 / 번역 세 개입니다.
- 고치기: ru.tsv, zh.tsv의 번역 칸을 고치면 그 줄이 모드 안의 번역보다 먼저 쓰입니다. 업데이트하면 이 두 파일은 새것으로 덮어써지니, 고친 파일은 다른 이름으로 따로 보관해 주세요.
- 새 언어: template.tsv를 복사해 이름을 바꾸고(예: de.tsv) 번역 칸을 채운 뒤, F12에서 "Language · 언어"를 Custom으로, "Custom language file · 사용자 번역 파일"에 그 파일 이름을 적으면 됩니다. 비워 둔 줄은 영어로 나옵니다.
- 확인: 파일을 읽고 덮어쓰는 동작은 자동 검사로 확인했고, 게임에서 직접 만든 파일을 넣어 본 것은 아직입니다.

3) 창고 보험 표시를 바꾸거나 끌 수 있습니다

- 전에는: 강화한 장비마다 칸 왼쪽 위에 보험 등급 글자 칸(P·고·일·X)이 붙었고, 보험을 안 든 장비에도 회색 X가 붙었습니다. 강화 장비가 많을수록 창고가 지저분해 보인다는 의견을 받았습니다.
- 이제: 기본 표시를 칸 왼쪽 아래 모서리의 작은 색 삼각형으로 바꿨고, 보험에 든 장비에만 붙습니다. 금색은 프리미엄, 파랑은 고급, 초록은 일반입니다.
- 설정: F12 "1. 기본"에 세 가지를 넣었습니다.
  "창고 보험 표시 모양" — 모서리 삼각형(기본), 1.4.0 글자 칸, 작은 점, 이름 옆 [P], 끄기
  "창고 보험 표시 위치" — 왼쪽 아래(기본), 왼쪽 위(1.4.0 자리), 오른쪽 아래 숫자 옆
  "보험 없는 강화 장비에도 표시" — 켜면 1.4.0처럼 보험 없는 장비에도 회색 표시가 붙습니다(기본 꺼짐)
- 바꾸면 창고를 다시 열지 않아도 바로 적용됩니다.
- 확인: 게임에서 기본 삼각형 표시와 F12 설정 화면을 확인했습니다. 다른 모양과 위치는 아직 게임에서 하나하나 확인하지 못했습니다.

[GIF 2: 창고 보험 표시 — 강화한 M4A1에 프리미엄 보험을 들자 칸 왼쪽 아래에 금색 삼각형이 생기는 모습]

4) 기타

- 서버와 클라이언트가 주고받는 버전이 올라서, 둘 다 1.4.1로 바꿔야 합니다. 한쪽만 바꾸면 강화 창에서 둘 다 업데이트하라는 안내가 나오고 진행을 막습니다. 저장된 강화 기록은 지우지 않습니다.
- 1.4.0의 강화·진화·초월·신화·보험·프레스티지 기록과 F12 설정은 그대로 이어집니다.

혹시 삼각형 표시가 거슬리면 F12 "창고 보험 표시 위치"를 왼쪽 위로 바꾸거나 "창고 보험 표시 모양"을 끄기(Off)로 고르시면 됩니다. 1.4.0 모양 그대로가 좋으시면 모양을 Letter, 위치를 Top Left, "보험 없는 강화 장비에도 표시"를 켜시면 됩니다.

■ 알아 두실 점

- 무기 칸은 왼쪽 아래에 탄 구경 글자가 있어서 삼각형이 그 첫 글자 바로 옆에 붙어 보입니다.
- 러시아어·중국어 번역이 어색한 곳을 알려 주시거나 lang 파일을 고쳐 보내 주시면 다음 버전에 넣겠습니다.

■ 설치

1. SPT 4.1.6을 사용합니다. 서버와 게임을 끄고 프로필을 백업합니다.
2. GearEnhance-1.4.1.zip을 SPT 폴더에 풀어 덮어씁니다. 클라이언트와 서버가 함께 들어 있고, fonts 폴더와 새 lang 폴더도 같이 들어갑니다.
3. 서버와 게임을 다시 켭니다.

■ 버그 제보

어떤 장비에서 무엇을 했는지, 사용 중인 언어, 화면 스크린샷과 BepInEx/LogOutput.log를 같이 주시면 빨리 봅니다.
