## Gear Enhance 1.4.2

**- 터미널 레이드 강화 풀림·장비칸 표시 겹침·다른 언어 글자 잘림 수정, 패널티 없는 방어구 충격 흡수 (1.4.1 대비)**

■ 바뀐 것
- 터미널: 탈출하면 강화가 풀리고 보험 우편으로 장비가 하나 더 오던 문제를 고쳤습니다. 터미널이 장비를 되돌리는 레이드는 기어 인핸스가 손대지 않습니다. 이미 풀린 강화는 돌아오지 않습니다.
- 장비칸: 신화·초월 단계 줄이 탄 종류 글자를 가리던 문제를 고쳤습니다(표시가 뜬 뒤 다시 자리를 잡음).
- 글자 잘림: 영어·러시아어·중국어에서 긴 글자는 자동으로 작아지고, MYTHIC의 y 같은 아래 획이 안 잘립니다.
- 충격 흡수: 패널티가 하나도 없는 방어구는 기동성 항목이 충격 흡수로 바뀌어 같은 수치만큼 둔탁상을 줄입니다. 패널티를 없애고 쓰는 경우 모든 방어구가 해당됩니다.
- 신화 추가 보호 부위: 아이템 상세 보기에는 원래 안 나옵니다(정상). F12 "자세한 로그 남기기"를 켜면 막을 때 로그에 남습니다.
(모두 게임 확인)

■ 설치
- ZIP을 SPT 폴더에 덮어쓰기. 클라이언트·서버를 같이 1.4.2로 바꿔 주세요(1.4.1과 섞여도 막히진 않지만 수정이 양쪽에 있음).

■ 주의
