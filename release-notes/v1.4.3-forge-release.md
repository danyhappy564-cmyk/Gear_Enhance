## Gear Enhance 1.4.3 — EquipmentIsEternal compatibility

**SPT 4.1.6 · Client + Server 1.4.3 · Protocol 13**

### EquipmentIsEternal compatibility
EquipmentIsEternal gives back your pre-raid gear when you die, restoring it with the same item ids right before the profile is saved. Gear Enhance previously treated that gear as lost first, wiping its enhancement records and, if enhancement insurance was active, mailing a duplicate. When EquipmentIsEternal is installed, the gear it is about to restore — following its own config (`OnlyRestoreInsured`, arm band, scabbard, secure container, special slots) — now keeps its enhancements even without enhancement insurance; the insurance is not used up and nothing is mailed. Gear it does not restore, such as items picked up in the raid, is handled by enhancement insurance as before. Servers without the mod are unaffected; if its layout changes and cannot be read, one warning is logged and the old behavior applies.

### Install / update

Stop the server and game, back up your profile, and extract `GearEnhance-1.4.3.zip` into your SPT folder, replacing both client and server. Protocol 13 is unchanged and the fix is server-side, but update both so the versions match. Existing records and F12 settings carry over.

### Verification and known issues

The creator confirmed in game on October 31, with EquipmentIsEternal on default settings, that weapons, armor and backpack contents came back enhanced after death.

With EquipmentIsEternal, gear covered by trader insurance can also be returned by the trader as an extra +0 copy. That is between EquipmentIsEternal and SPT's own insurance and Gear Enhance does not block it; EquipmentIsEternal users accept this. The copy does not carry Transcendence max durability. This case was not tested in game.

With EquipmentIsEternal's `DeduplicateItems` set to false, a plate moved to another container during the raid can receive the Transcendence durability bonus a second time after death. Default settings are not affected.

A report says ammunition stacks break when used with CobrasAmmoStack. Gear Enhance has no code that changes ammunition stacks, and the cause is still unknown. If this happens, please send the symptoms and server log.
