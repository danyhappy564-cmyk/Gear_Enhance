## Gear Enhance 1.4.2 — Terminal raid recovery, display fixes, and impact absorption

**SPT 4.1.6 · Client + Server 1.4.2 · Protocol 13**

### 1. Terminal raid recovery
Manimal Terminal restores pre-raid equipment and blocks trader insurance at the end of a raid. Gear Enhance previously treated that gear as lost first, deleting enhancement records and, if enhancement insurance was active, sending a duplicate by mail. Enhancement insurance raid-end processing is now skipped when Terminal restores the gear. Already deleted records cannot be recovered.

### 2. Mythic and Transcendence labels
The game filled caliber text after drawing the equipment cell, causing the progression label to cover it until the enhancement window opened. The label now repositions four times within two seconds after appearing.

### 3. Text clipping
Long single-line English, Russian, and Chinese text now shrinks automatically to as little as 70%, and descenders such as y, g, and р no longer get clipped, including the MYTHIC achievement title.

### 4. Impact absorption
When an armor item and its plates have no movement, turn speed, or ergonomics penalties, Mobility instead reduces blunt damage by 2% per level, up to 20%, with star bonuses. Actual penalties are checked per item: changing a plate to one with a penalty switches the effect back to penalty reduction. Existing Mobility levels apply, enhancement levels and evolution requirements are unchanged, and the effect multiplies with Transcendence blunt damage reduction. The enhancement window, result window, and stat panel show the current effect.

### 5. Mythic additional protection zones
Additional zones change hit checks at the moment of impact, so the game's item inspect view normally shows only the original zones. Enable F12 `Detailed logging` to record blocked hits in `LogOutput.log`, at most once per zone every five seconds.

### Install / update

Stop the server and game, back up your profile, and extract `GearEnhance-1.4.2.zip` into your SPT folder, replacing both client and server. Protocol 13 is unchanged: mixing 1.4.1 and 1.4.2 does not block the enhancement window, but update both sides to receive all fixes. Existing records and F12 settings carry over.

### Verification and known issue

The creator confirmed all changes in game on October 28 and found no issues.

A report says ammunition stacks break when used with CobrasAmmoStack. Gear Enhance has no code that changes ammunition stacks, and the cause is still unknown. If this happens, please send the symptoms and server log.
