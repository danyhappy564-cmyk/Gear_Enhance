# Gear_Enhance v1.4.1

**태그:** `1.4.1` · 라이선스 MIT · SPT 4.1.6 · 통신 버전 13 (클라이언트·서버 모두 1.4.1)

**이전 릴리즈:** v1.4.0 (GitHub 릴리즈 `1.4.0`, 그 뒤 커밋 6개) → **이번: v1.4.1** (러시아어·중국어 추가, 직접 고치는 번역 파일, 창고 보험 표시 설정)

**<변경점>**

**1. 러시아어·중국어(간체)를 추가했습니다**

- 해외 유저분이 러시아어 번역을 요청해 주셔서, 러시아어와 중국어 간체를 함께 넣었습니다.
- 강화 창 위쪽 언어 버튼이 `한국어 · EN · RU · 中文` 4개가 되었습니다. 누르면 강화 창·오른쪽 장비 상태·결과 팝업까지 바로 바뀝니다. F12 `0. Language · 언어` → `Language`에도 `Russian`·`Chinese`가 생겼습니다.
- `Auto`(기본)는 윈도우 언어를 보고 고릅니다: 한국어 → 한국어, 러시아어·우크라이나어·벨라루스어 → 러시아어, 중국어 → 중국어, 그 밖 → 영어.
- 번역 범위: 강화 창 전체, 결과 팝업, 창고 표식, F12 일반 설정, **서버 오류 안내**(서버가 번역용 열쇠를 같이 보내서 숫자까지 그 언어로 나옵니다). 비밀번호로 여는 개발자 옵션만 영어로 둡니다.
- 중국어를 고르면 강화 창 글꼴이 Windows 중국어 글꼴(Microsoft YaHei)로 바뀝니다. 기본 글꼴(Noto Sans KR)에는 한자가 없기 때문입니다.
- 러시아어는 칸에서 잘리기 쉬운 짧은 이름 35개를 줄여 썼습니다.
- 확인: 게임에서 네 언어 전환과 중국어 글꼴 표시를 확인했습니다. 러시아어·중국어 문구는 아직 원어민 검토를 받지 않았습니다.

![강화 창 언어 버튼으로 한국어 → EN → RU → 中文 전환](https://raw.githubusercontent.com/danyhappy564-cmyk/Gear_Enhance/d87575396edb90b96349a7eca3910c2d4d85adc0/assets/forge/1.4.1/language-switch.gif)

*위: 강화 창 위쪽 버튼으로 한국어 → 영어 → 러시아어 → 중국어로 바꾸는 모습. 오른쪽 장비 상태 패널도 같이 바뀝니다.*

**2. 번역 파일을 직접 고치거나 새 언어를 만들 수 있습니다**

- `BepInEx/plugins/GearEnhance/lang/`에 `ru.tsv`·`zh.tsv`·빈 틀 `template.tsv`가 들어 있습니다. 탭으로 나눈 UTF-8 표라 메모장·엑셀·구글 시트로 열 수 있고, 칸은 `ko`(열쇠, 고치지 않음) · `en`(참고) · `text`(번역)입니다.
- `ru.tsv`·`zh.tsv`에서 고친 줄은 DLL 안의 번역보다 먼저 쓰입니다. 업데이트하면 이 두 파일이 덮어써지므로 고친 파일은 다른 이름으로 보관해 주세요.
- 새 언어는 `template.tsv`를 `de.tsv`처럼 복사해 `text` 칸을 채운 뒤, F12 `Language = Custom`, `Custom language file = de.tsv`로 고릅니다. 빈 칸이나 `-`는 영어로 나옵니다. `{0}` 같은 자리 표시와 칸 앞뒤 공백은 그대로 두고, 줄바꿈은 `\n`으로 적습니다.
- 확인: 파일 읽기·덮어쓰기·사용자 파일은 자동 검사로 확인했고, 게임에서 사용자 파일을 직접 넣어 본 것은 아직입니다.

**3. 창고 보험 표시를 바꾸거나 끌 수 있습니다**

- 1.4.0은 강화한 장비마다 칸 왼쪽 위에 18px 글자 칸(P·고·일·X)을 붙였고, 보험이 없는 장비에도 회색 X가 붙었습니다. 해외 유저분이 "보험 아이콘 위치가 거슬린다, 끄거나 옮길 수 있으면 좋겠다"고 알려 주셨습니다.
- 기본 표시를 **칸 왼쪽 아래의 작은 색 삼각형**으로 바꾸고, **보험에 든 장비만** 표시합니다. 색: 금색 = 프리미엄, 파랑 = 고급, 초록 = 일반.
- F12 `1. 기본`에 설정 3개를 넣었습니다:
  - `창고 보험 표시 모양`: `Corner`(모서리 삼각형, 기본) · `Letter`(1.4.0 글자 칸) · `Dot`(작은 점) · `Name Tag`(이름 별 뒤에 `[P]`) · `Off`(끄기)
  - `창고 보험 표시 위치`: `Bottom Left`(왼쪽 아래, 기본) · `Top Left`(1.4.0 자리) · `Beside Count`(오른쪽 아래 개수·내구도 숫자 옆)
  - `보험 없는 강화 장비에도 표시`: 켜면 1.4.0처럼 보험 없는 장비에도 회색 표시(글자 칸은 X). 기본은 꺼짐.
- 설정을 바꾸면 창고를 다시 열지 않아도 바로 다시 그립니다.
- 확인: 게임에서 기본 모서리 표시와 F12 설정 화면을 확인했습니다. 다른 모양·위치는 자동 검사와 시안(목업)으로만 확인했습니다.

![보험에 가입하면 창고 칸 왼쪽 아래에 금색 삼각형이 붙는 모습](https://raw.githubusercontent.com/danyhappy564-cmyk/Gear_Enhance/d87575396edb90b96349a7eca3910c2d4d85adc0/assets/forge/1.4.1/stash-insurance-corner.gif)

*위: 강화 무기(+1)에 프리미엄 보험을 들자 칸 왼쪽 아래에 금색 삼각형이 생기는 모습.*

**4. 기타**

- 통신 버전이 12에서 13으로 올랐습니다. 클라이언트와 서버를 같이 1.4.1로 바꿔야 하며, 한쪽만 바꾸면 강화 창이 양쪽 업데이트를 안내하고 진행을 막습니다(저장 기록은 지우지 않음).
- 빌드할 때 번역이 빠진 문구가 있으면 빌드가 멈추도록 검사를 넣었습니다(`tools/lang.py`).
- 검사: 서버 257개 · 클라이언트 173개 통과, 빌드 경고·오류 0.

**알려진 점**

- 무기 칸은 왼쪽 아래에 탄 구경 글자가 있어서, 모서리 삼각형이 첫 글자 바로 옆에 붙어 보입니다. 거슬리면 F12 `창고 보험 표시 위치`를 `Top Left`로 바꾸거나 모양을 `Off`로 고르시면 됩니다.
- 러시아어·중국어는 원어민 검토 전입니다. 어색한 문장은 `lang` 폴더 파일로 고쳐 보내 주시면 반영하겠습니다.
- 1.4.0으로 되돌릴 때는 클라이언트·서버를 같이 되돌려 주세요. 강화 기록 형식은 바뀌지 않았습니다.

**<Changes (English)>**

**1. Russian and Simplified Chinese**

- A player asked for a Russian translation, so Russian and Simplified Chinese were both added.
- The language buttons at the top of the enhancement window are now `한국어 · EN · RU · 中文`. They switch the window, the stat panel and the result pop-ups at once. F12 `0. Language · 언어` → `Language` also has `Russian` and `Chinese`.
- `Auto` (default) follows Windows: Korean → Korean, Russian/Ukrainian/Belarusian → Russian, Chinese → Chinese, anything else → English.
- Translated: the whole enhancement window, result pop-ups, stash markers, regular F12 settings and **server error messages** (the server now sends a translation key, so numbers show in that language too). Only the password-protected developer options stay in English.
- In Chinese the window uses the Windows Chinese font (Microsoft YaHei); the bundled Noto Sans KR has no Chinese characters.
- Confirmed in game: switching between all four languages and the Chinese font. The Russian and Chinese text has not been reviewed by native speakers yet.

![Switching the enhancement window between Korean, English, Russian and Chinese](https://raw.githubusercontent.com/danyhappy564-cmyk/Gear_Enhance/d87575396edb90b96349a7eca3910c2d4d85adc0/assets/forge/1.4.1/language-switch.gif)

**2. Translation files you can edit or extend**

- `BepInEx/plugins/GearEnhance/lang/` contains `ru.tsv`, `zh.tsv` and a blank `template.tsv`: UTF-8, tab-separated, columns `ko` (key, do not change), `en` (reference), `text` (translation).
- Rows you edit in `ru.tsv` / `zh.tsv` win over the built-in translation. Updates overwrite these two files, so keep your edits under another name.
- New language: copy `template.tsv` (e.g. to `de.tsv`), fill `text`, then set F12 `Language = Custom` and `Custom language file = de.tsv`. Empty cells or `-` show English. Keep `{0}` placeholders and leading/trailing spaces; write line breaks as `\n`.

**3. Stash insurance mark can be restyled, moved or turned off**

- 1.4.0 put an 18 px letter badge (P · A · B · X) at the top left of every enhanced item, including a grey X on uninsured gear. A player said it got in the way and asked for a way to move it or turn it off.
- The default is now a **small colored triangle in the lower-left corner**, on **insured gear only** (gold = Premium, blue = Advanced, green = Basic).
- New F12 `1. General` settings: `Stash insurance mark` (`Corner` default · `Letter` · `Dot` · `Name Tag` · `Off`), `Stash insurance mark position` (`Bottom Left` default · `Top Left` · `Beside Count`), and `Mark uninsured enhanced gear too` (off by default). Changes redraw the stash immediately.
- Confirmed in game: the default corner mark and the F12 settings. Other shapes and positions were checked by automated tests and the mockup only.

![A gold corner mark appears in the lower-left of the cell after the weapon is insured with Premium](https://raw.githubusercontent.com/danyhappy564-cmyk/Gear_Enhance/d87575396edb90b96349a7eca3910c2d4d85adc0/assets/forge/1.4.1/stash-insurance-corner.gif)

**4. Other**

- Protocol 12 → 13: update both client and server to 1.4.1. A mismatch shows an "update both" message and blocks actions without deleting records.
- The build now stops if any text is missing a Russian or Chinese row (`tools/lang.py`).
- Tests: server 257 · client 173 passed, build warnings/errors 0.

**Known issues**

- Weapon cells show the caliber at the lower left, so the corner triangle sits right next to its first letter. If it bothers you, set `Stash insurance mark position` to `Top Left` or the mark to `Off`.
- Russian and Chinese have not had a native-speaker review. Fixes sent as `lang` files are welcome.
- To go back to 1.4.0, downgrade client and server together. The record format did not change.

**Install / update**

1. SPT 4.1.6. Stop the server and game and back up your profile.
2. Extract `GearEnhance-1.4.1.zip` into the SPT folder, overwriting `BepInEx/plugins/GearEnhance/` (with `fonts` and `lang`) and `SPT_Runtime/user/mods/GearEnhance/`.
3. Restart. All 1.4.0 records and F12 settings carry over.
