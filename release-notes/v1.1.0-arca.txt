Gear Enhance v1.1.0 — 영어 화면 추가, 보험·플리마켓으로 돌아온 장비도 강화가 그대로

[구분선]

■ 바뀐 것

1) 한국어 / 영어 전환 (새 기능)
- 전에는: 모든 화면이 한국어뿐이라 외국 분들은 쓰기 어려웠습니다.
- 이제: F12 맨 위 "Language · 언어"에서 Auto / Korean / English 중에 고르면 됩니다. 기본값 Auto는 윈도우가 한국어면 한국어, 아니면 영어로 나옵니다.
- 바뀌는 곳: 강화 창, 스타 진화 창, 결과 창, 우클릭 메뉴, 창고의 별 표식 글자, 서버에서 오는 오류 안내, F12 설정 이름과 설명까지 전부입니다.
- 알아 둘 점: 열려 있는 강화 창은 바로 바뀌고, 창 아래 안내 한 줄만 다음 안내부터 바뀝니다. F12 설정 글자는 F12 창을 닫았다가 다시 열어야 바뀝니다.
- 언어를 바꾸거나 1.0.0에서 올려도 기존에 맞춰 둔 설정값은 그대로입니다. 버그 제보용 로그 파일 안의 글은 한국어 그대로 둡니다.
- 확인: 아직 게임에서 확인 못 했습니다. 영어 문장이 길어서 칸 밖으로 잘리는 곳이 있으면 스크린샷 부탁드립니다.

2) 보험으로 돌려받은 장비, 플리에서 돌아온 장비도 강화가 그대로 (고친 것)
- 전에는: 강화한 장비를 보험으로 돌려받거나, 플리마켓에 올렸다가 안 팔려 만료되거나 직접 내려서 우편으로 돌아오면 강화 안 된 새 장비처럼 돌아왔습니다. 1.0.0 글에 "알아 두실 점"으로 적었던 부분입니다.
- 왜: 게임 서버가 우편으로 물건을 보낼 때 그 물건을 복사해서 새 이름표를 붙여 보냅니다. 강화 기록은 옛 이름표에 묶여 있어서, 돌아온 장비를 같은 장비로 알아보지 못했습니다.
- 이제: 서버가 우편을 보내는 순간 "옛 이름표 → 새 이름표" 짝을 받아 두고, 항목별 강화 단계와 2스타·3스타 진화를 돌아온 장비로 그대로 옮깁니다.
- 보험 대기 중이거나 플리에 올려 둔 동안, 우편함에 들어 있는 동안에는 창고에 없어도 기록을 지우지 않습니다. 전에는 창고에 없는 장비 기록을 정리해 버렸습니다.
- 우편에서 장비를 꺼내면 몇 초 안에 별 표식과 강화 능력치가 붙습니다(레이드 밖에서만 다시 확인합니다).
- 같은 장비가 두 개로 늘어나는 일이 없도록, 지금 갖고 있는 장비를 복사해 보내는 우편이나 개수·종류가 안 맞는 우편에는 기록을 옮기지 않습니다.
- 확인: 게임 서버의 실제 이름표 바꾸는 부분을 그대로 써서 보험·플리 반환을 흉내 낸 검사에서 강화 단계와 3스타가 이어지는 것은 확인했습니다. 실제 게임에서 보험·플리로 돌려받아 보는 확인은 아직입니다.

3) 기타
- 모드 아이콘을 새로 만들었습니다. 게임 동작과는 상관없습니다.
- 강화 확률, 비용, 효과 수치는 1.0.0과 똑같습니다.
- 자동 검사 211개가 모두 통과했습니다.

■ 알아 두실 점

- 1.0.0 이하에서 이미 돌려받아 강화가 사라진 장비는 기록이 지워진 상태라 되살릴 수 없습니다. 1.1.0을 설치한 뒤에 새로 잃거나 플리에 올린 장비부터 적용됩니다.
- 상인에게 판 장비는 지금도 강화가 이어지지 않습니다. 다시 사도 다른 물건으로 취급됩니다.
- 보험 상인이 부착물 일부를 안 돌려주면 돌아온 부분만 받습니다. 강화 기록은 돌아온 본체에 그대로 이어집니다.
- 영어로 바꿨는데 일부가 한국어로 남아 있으면 강화 창이나 F12 창을 닫았다가 다시 열어 주세요.
- 여러 명이 같이 하는 환경(Fika)은 지원하지 않습니다.
- 혹시 이상하면 F12 "Language · 언어"를 Korean으로 두거나, 1.0.0 압축 파일로 다시 덮어쓰면 됩니다. 창고에 있는 장비 기록은 남지만, 1.0.0으로 되돌린 동안에는 보험 대기·플리 판매 중인 장비 기록이 예전처럼 지워질 수 있습니다.

■ 설치

GearEnhance-1.1.0.zip 을 풀어서 SPT 폴더에 덮어쓰기 하면 됩니다. 클라이언트와 서버가 한 압축 파일에 같이 들어 있으니 둘 다 1.1.0으로 바꾸고 서버와 게임을 다시 켜 주세요. 강화 단계, 진화 기록, 설정은 그대로 남습니다. 클라이언트나 서버 한쪽만 1.0.0으로 남아 있으면 강화는 되지만, 돌아온 장비 기록 연결과 영어 오류 안내는 동작하지 않습니다.

■ 버그 제보

스크린샷 + BepInEx/LogOutput.log 같이 주시면 빨리 봅니다. 돌아온 장비에 강화가 안 붙었다면 보험인지 플리인지, 우편에서 꺼낸 뒤 몇 초 기다렸는지도 같이 알려 주세요.
